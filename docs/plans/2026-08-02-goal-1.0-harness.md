## Integration contracts (shared by all workstreams)

1. **Fixture layout** (repo root `tests/fixtures/`):
   - `small/` — Dart pkg, 1-2 lib files, ~10-15 mutants, all killed, <5 s
   - `medium/` — Dart pkg, 3-4 lib files, 50-80 mutants, mixed outcomes (killed/survived/timeout), <30 s
   - `large/` — Dart pkg, 8-10 lib files, 200+ mutants, MSI ~65%, <5 min
   - `flutter/` — Flutter pkg (created by workstream F, not D)
   - Each fixture: `pubspec.yaml` (name `fixture_*`, sdk `^3.0.0`, dev_deps: test), `lib/`, `test/`, `.dart_mutant.yml` where needed
2. **Agent JSON contract**: `PipelineSummary` gains `schemaVersion: "1.0"` field (serde rename). All other fields unchanged.
3. **Binary path**: integration tests use `env!("CARGO_BIN_EXE_dart-mutant")`; fixtures resolved via `CARGO_MANIFEST_DIR` → `../../tests/fixtures/<name>`.
4. **Routing test trick**: a slow test (5 s sleep) in a file that covers nothing; routing test asserts total run < 10 s (proves non-covering tests skipped).
5. **Scale gate**: `scale.rs` integration test marked `#[ignore]`; CI runs it explicitly (`-- --ignored`). Cold < 600 s, warm < 30 s on `large/`.
6. **TCE test**: run `--detect-equivalent` on `medium/` + `large/`; assert ≥1 equivalent classified, no crash, MSI computed excluding equivalents.
7. **Reports test**: Stryker JSON parses + `schemaVersion: "2"`; JUnit XML well-formed; HTML contains statuses.
8. **Branch policy**: each workstream on its own branch; parent merges sequentially to main after local verification. No direct main pushes by subagents.

## Deviations from plan (all justified)

1. **Routing test**: timing-based <10s assertion replaced with a behavioral
   marker-count proof (machine-independent; per-mutant JIT spawns dominate
   wall-clock so timing was flaky).
2. **Cache was inert** — the scaffold existed but the scheduler ignored it.
   Wired end-to-end (wf-cache branch): lookup-before-run, deferred stores,
   `from_cache` stat. Required for the warm <30s scale gate.
3. **Parallel test corruption** — integration tests mutate shared fixture
   files; cargo's parallel threads corrupted runs (observed killed=0). Fixed
   with a global fixture lock in `tests/common/mod.rs` + `--test-threads=1`
   in CI.
4. **MSI targets** drifted from contract (~65% → 84.5% large) because
   unasserted functions are now *called* (covered-but-unasserted → SURVIVED,
   not NOT_COVERED). More realistic; contract's kill-mix present.
5. **`dart pub get`** added to CI (fixtures ship pubspec.lock; `.dart_tool`
   is gitignored — fresh checkouts would fail without resolution).
6. **Flutter LCOV baseline** would have misclassified every mutant SURVIVED
   (`--plain-name baseline` matches nothing) — fixed to run full suite.
